# N3U AgentX Ubench log links

**48 run links: 25 agg and 23 disagg.** These AgentX benchmark jobs ran AIPerf. Each log link opens the original `logs/aiperf.log` object in Google Cloud Storage; sign in with an account that can access the bucket. This page contains links only.

[Serving performance report](agentx-serving-perf-report.md) · [Agg source results](../AGENTX_AGG_RESULTS.md) · [Disagg source results](../AGENTX_D88_RESULTS.md)

The list covers all 45 hardware jobs in the serving report, plus three additional completed disagg jobs. Curve entries match the default KV/RR curves; the other sections identify tuning and additional runs separately. Agg uses 24 GPUs; disagg D88 uses 64 GPUs.

KV defaults are load scale 1, overlap credit 1, credit decay 0, temperature 0, and FCFS. Tuning rows list changes to these defaults: `load` = `--router-prefill-load-scale`, `credit` = `--router-kv-overlap-score-credit`, `decay` = `--router-kv-overlap-score-credit-decay`, and `temperature` = `--router-temperature`.

Source snapshot: [`b556bec2eadb`](https://github.com/alisachen-google/gcp-dynamo-cuj/tree/b556bec2eadbadabd18ef110e75c3bdcba6bff1a). All 48 log objects were checked to exist. Distinct artifact folders distinguish jobs with the same routing flags and concurrency.
